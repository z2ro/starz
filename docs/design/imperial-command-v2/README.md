# STARZ — Imperial Command V2

Pacote de direção visual e UX aprovado para a experiência principal do STARZ.

Este diretório é um handoff de design. Ele não substitui a implementação existente e não define dados de gameplay. A implementação deve reutilizar o shell atual, conectar os componentes ao estado real da API e preservar as rotas e ações existentes.

## Conteúdo

- `VISUAL-SYSTEM.md` — tokens, tipografia, grid, shell, estados, motion e iconografia.
- `SCREEN-SPECS.md` — especificações de Planet, Overview, Economy, Research, Shipyard, Fleets e Galaxy.
- `ASSET-MANIFEST.md` — composição do hero, camadas e requisitos de assets.
- `CODEX-HANDOFF.md` — ordem de implementação, mapeamento de dados e critérios de aceite.
- `assets/` — referências visuais aprovadas e sheets de exploração.

## Fonte aprovada

**Direction 01 — Imperial Command**: comando imperial, espaço profundo em navy, acentos ice-cyan, inspector operacional e operations deck contínuo.
