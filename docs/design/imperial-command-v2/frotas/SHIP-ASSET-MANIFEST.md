# STARZ — Ship Asset Manifest V3

## Capital ships

Para Leviathan, Atlas, Dominion e Stargrave-class:

- ortho front, side, top e rear;
- isometric view;
- blueprint / schematic;
- silhouette UI;
- material and color guide;
- functional callouts;
- visual scale relationship;
- Shipyard presentation preview;
- orbit / fleet context preview quando aplicável.
