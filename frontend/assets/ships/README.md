# STARZ runtime ship artwork

These PNGs are the approved visual design plates promoted from
`docs/design/imperial-command-v2/frotas/assets/`. They are presentation-only
assets for the Shipyard Design Catalog; they do not define gameplay stats or
build availability.

Runtime URLs are `/static/ships/<design-id>.png`. The React registry maps the
eleven primary designs and maps only `horizon` to the current gameplay hull
`scout_hull`. Missing gameplay mappings remain `CONCEITO` and never receive a
build action. Strike craft are subordinate to Atlas and are not catalog rows.
